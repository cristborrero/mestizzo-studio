## **12. Lógica de Negocio (Reglas del Cotizador)**

1. **Urgencia (Priority Track):** Entrega garantizada en menos de 48 horas añade un recargo automático del **40%** sobre el subtotal.
2. **Derechos y Fuentes:** La entrega de archivos fuente editables (.ai, .psd, .fig, .ae) añade un **25%** al valor de la pieza.
3. **Revisiones:** El costo incluye **2 rondas** de ajustes. Cada ronda adicional se factura a **$35.00 USD / hora**.
4. **Reserva de Proyecto:** El cotizador debe habilitar el pago de un **50% de anticipo** vía PayPal para iniciar cualquier servicio.
5. **SEM/SMM Fee:** El fee de administración requiere una inversión publicitaria mínima de **$1,000 USD**; de lo contrario, se aplica una tarifa fija mínima.

*Nota: Tasas de conversión sugeridas: $1 USD = $4,000 COP.*
